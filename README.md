# C13PowerDashboard

Локальний дашборд електроживлення будинку: мережа на вході інвертора, напруга на його виході, навантаження та заряд батареї. Адаптивний HTML/CSS/JavaScript інтерфейс і невеликий сервер Node.js. C# та сторонні npm-залежності не потрібні.

## Запуск на комп’ютері

Потрібен Node.js 22 або новіший.

1. Відкрийте **start.cmd**.
2. Сторінка відкриється за адресою http://localhost:3131.
3. При першому запуску натисніть кнопку налаштувань, введіть App ID, App Secret, email і пароль Deye та виберіть станцію.

Підключення і вибір станції зберігаються. Для зміни станції відкрийте налаштування. Якщо сервер уже запущений, достатньо відкрити сторінку; другий екземпляр запускати не потрібно. Зупинка сервера, запущеного цим файлом: Ctrl+C у його вікні.

Альтернатива: npm start. Файл index.html не потрібно відкривати подвійним клацанням: для Deye потрібен локальний сервер.

## Телефон у тій самій мережі

Зупиніть звичайний сервер і запустіть **start-lan.cmd** (або npm run start:lan). Відкрийте на телефоні адресу, яку сервер покаже у вікні. Комп’ютер і телефон повинні бути в одній довіреній локальній мережі. Windows може попросити дозволити Node.js доступ у приватній мережі.

На телефоні доступний перегляд. Змінювати облікові дані й станцію можна тільки через localhost на комп’ютері. Не відкривайте цей локальний сервер в інтернет через переадресацію портів. Коли комп’ютер вимкнений або спить, дашборд недоступний.

На широкому екрані плитки розміщені в ряд; до 760 px — одна під одною. Унизу є окремо позначені демонстраційні стани для перевірки оформлення.

## Що означають показники

- **Мережа на вході:** напруга й частота на вході інвертора. Нульова потужність сама по собі не означає зникнення мережі.
- **Вихід інвертора:** наявність напруги на виході. Навантаження показується лише коли вихід працює.
- **Заряд батареї:** SOC поточного вимірювання; для одного інвертора його параметри мають пріоритет перед зведеними даними станції.
- **З’явилася / Зникла ≈:** середина інтервалу між двома історичними вимірюваннями з різним станом. Це приблизний час. Якщо перехід не знайдений, рядок прихований.

Історія читається з Deye за день останнього вимірювання та попередній календарний день у часовому поясі Києва. Власний журнал показників не створюється. Час переходу показується для станції з одним інвертором; для кількох він прихований, щоб не змішувати події різних пристроїв.

Якщо генератор через АВР живить той самий вхід, ці показники не відрізняють генератор від зовнішньої мережі. Напруга на виході не підтверджує стан усіх споживачів після нього.

Вхід вважається наявним при 180–260 В на всіх очікуваних фазах і 45–55 Гц; відсутнім — при напрузі нижче 50 В та частоті нижче 1 Гц. Інші повні вимірювання позначаються нестабільними, відсутні — невідомими. Це правила індикації, не налаштування електричного захисту.

Сторінка запитує сервер щохвилини; це не прискорює передачу логером у хмару. Відповідь кешується на хвилину, історія — на п’ять хвилин, лише в оперативній пам’яті. Дані старші за 15 хвилин або помилка запиту дають стан «Невідомо».

## Збереження підключення

Налаштування зберігаються у .local/settings.json, зашифровані AES-256-GCM. Ключ лежить поруч у .local/key: це захист від випадкового розкриття тексту, а не від користувача з доступом до обох файлів. Вся папка .local виключена з Git і не видається вебсервером. Пароль, App Secret і токен Deye не надходять у відповіді браузеру. Сервер працює з європейським API для EMEA/APAC.

Не додавайте .local до GitHub. Для перенесення на інший комп’ютер краще заново налаштувати підключення через форму.

## Перевірки

npm test — перевірки визначення станів, часових поясів, історичних переходів, авторизації API, шифрування та меж доступу локального сервера.

Основні файли:
- public/ — інтерфейс;
- server.mjs — локальний сервер;
- lib/deye.mjs — Deye API;
- lib/domain.mjs — інтерпретація показників та історії;
- lib/settings.mjs — збереження підключення.

tools/import-settings.mjs — допоміжний імпорт уже розшифрованої конфігурації старої програми через стандартний ввід. Не передавайте паролі аргументами командного рядка.

## GitHub Pages

Другий режим підготовлено: інструкція у GITHUB-PAGES.md.
npm run build:pages — збірка з GitHub Secrets через змінні середовища.
npm run build:pages:local — перевірка статичного сайту з наявним локальним підключенням.
Результат dist/index.html читає data/status.json; локальний public/index.html використовує сервер Deye.
