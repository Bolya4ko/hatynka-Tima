# C13PowerDashboard

Дашборд електроживлення будинку: мережа на вході інвертора, робота інвертора та заряд батареї. Це статична сторінка (HTML/CSS/JavaScript), яка читає дані з невеликого Cloudflare Worker. Worker входить у Deye Cloud і віддає лише готові показники, без паролів.

```
Deye Cloud  →  Cloudflare Worker (worker/)  →  сторінка (public/)
```

## Перегляд сторінки

Відкрийте `public/index.html` у VS Code через Live Server (Go Live). Збірка не потрібна. Дані сторінка бере з Worker за адресою в `<meta name="dashboard-api">` у `public/index.html`.

Додатково в адресі:
- Унизу сторінки є перемикач «Перегляд» із прикладами (мережа є / немає, дані застаріли, завантаження) для перевірки оформлення;
- `?api=http://127.0.0.1:8787` — сторінка бере дані з Worker, запущеного на вашому комп’ютері (`npx wrangler dev`), а не з хмарного. Дозволено лише localhost;
- `?station=ID` — відкриває іншу станцію зі списку `ALLOWED_STATION_IDS` у `wrangler.toml`. Без параметра показується головна станція.

## Worker

Файли: `worker/index.mjs`, `wrangler.toml`. Секрети (App ID, App Secret, логін і пароль Deye) зберігаються лише в Cloudflare.

- Локальний запуск: скопіюйте `.dev.vars.example` у `.dev.vars`, впишіть значення, потім `npx wrangler dev` і відкрийте `http://127.0.0.1:8787/api/status`.
- Публікація: `npx wrangler deploy`.
- Секрети: `npx wrangler secret put DEYE_APP_ID` (аналогічно `DEYE_APP_SECRET`, `DEYE_LOGIN`, `DEYE_PASSWORD`).
- Кеш відповіді налаштовується в `wrangler.toml` (`CACHE_SECONDS`). Заголовки `X-Cache` і `X-Cache-Age` показують, чи відповідь узято з кешу.
- Історія переходів (мережа з’явилась / зникла) вантажиться лише коли з’явилося нове вимірювання інвертора; завершений день вантажиться один раз. Це зменшує навантаження на процесор Worker.

Логер Deye передає дані в хмару приблизно раз на 5 хвилин; Worker цю затримку не збільшує, але й не прискорює.

## Публікація сторінки на GitHub Pages

Workflow `.github/workflows/pages.yml` копіює `public/` у `dist/` (`npm run build`) і публікує. Секрети Deye йому не потрібні. Для автозапуску після кожного push додайте в `on:` гілку `main` (приклад у файлі).

## Що означають показники

- **Мережа на вході:** напруга й частота на вході інвертора. Нульова потужність сама по собі не означає зникнення мережі.
- **Робота інвертора:** стан визначається з урахуванням АВР: «Будинок живиться від інвертора» лише без мережі та за наявності напруги й навантаження на виході; при наявній мережі — «Інвертор заряджає акумулятор» або «у режимі очікування».
- **Стан батареї:** SOC поточного вимірювання.
- **З’явилася / Зникла ≈:** середина інтервалу між двома історичними вимірюваннями з різним станом. Це приблизний час; якщо перехід не знайдений, рядок прихований.

Вхід вважається наявним при 180–260 В на всіх очікуваних фазах і 45–55 Гц; відсутнім — при напрузі нижче 50 В та частоті нижче 1 Гц. Дані старші за 1 годину дають стан «Невідомо». Якщо генератор через АВР живить той самий вхід, ці показники не відрізняють його від міської мережі.

## Перевірки

`npm test` — визначення станів, часові пояси, історичні переходи, авторизація Deye API, Worker (кеш, список станцій, відсутність секретів) і підготовка сторінки.
