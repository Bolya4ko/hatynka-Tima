# Deye Power Dashboard

Особистий дашборд для гібридного інвертора Deye SUN-6K-SG05LP1-EU-AM2-P. Сторінка показує мережу, роботу інвертора, заряд батареї, споживання будинку та сонячну генерацію.

```
Deye Cloud → Cloudflare Worker → статична сторінка
```

## Показники

- Мережа на вході інвертора та приблизний час її появи або зникнення.
- Стан виходу інвертора, поточне споживання й заряд батареї.
- Поточна потужність сонячних панелей та виробіток за сьогодні.

Дані з Deye Cloud зазвичай надходять раз приблизно на п’ять хвилин. Коли вимірювання старше години, дашборд показує, що дані застаріли.

## Налаштування

1. Скопіюйте `.dev.vars.example` у `.dev.vars`.
2. У `.dev.vars` введіть дані Deye Cloud та ID вашої станції. Цей файл вже виключено з Git.
3. У `wrangler.toml` укажіть ID станції та бажану назву, яку побачите на сторінці.
4. Запустіть Worker локально: `npx wrangler dev`.
5. Відкрийте `public/index.html` через Live Server, додавши до адреси `?api=http://127.0.0.1:8787`.

Для публікації Worker виконайте `npx wrangler deploy`, внесіть отриману адресу у метатег `dashboard-api` у `public/index.html`, а секрети задайте окремо командою `npx wrangler secret put` для `DEYE_APP_ID`, `DEYE_APP_SECRET`, `DEYE_LOGIN` та `DEYE_PASSWORD`.

## Перевірка

`npm test` перевіряє отримання та очищення даних, стани живлення, сонячні показники, кеш Worker і те, що секрети не потрапляють на сторінку.
